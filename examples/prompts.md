# Prompt 示例

下面这些 prompt 可以直接复制到你的 AI 工具里使用。

---

## 只做配图规划

```text
Use $cang-skill 先不要生图。
请分析下面这篇文章哪里值得配图，输出 5 张左右的 shot list。
每张图写清楚：
- 放在哪个段落后
- 图的主题
- 核心意思
- 结构类型
- 仓老师在图里做什么
- 建议元素
- 建议中文标注词

<粘贴文章>
```

---

## 文章正文配图

```text
Use $cang-skill 把下面这篇文章生成 4 张仓老师怪诞正文配图。
要求：16:9 横版、纯白背景、黑色手绘线稿、少量红橙蓝中文手写批注。
每张图只讲一个核心结构，不要做 PPT 信息图，不要可爱卡通。

<粘贴文章>
```

---

## 长文配图策略

```text
Use $cang-skill 给这篇长文做配图策略。
不要平均配图，只挑认知锚点：核心判断、输入输出闭环、前后对比、常见坑、承接路径。
默认 6-8 张，先输出 shot list，不要生成图片。

<粘贴文章>
```

---

## 单个观点生成一张图

```text
Use $cang-skill 为这个观点生成一张 16:9 正文配图：

<粘贴你的核心观点>

画面要怪诞但清爽，仓老师必须承担核心动作。
中文标注最多 5 个，短一点。
```

---

## 工作流主题

```text
Use $cang-skill 为"<你的工作流主题>"生成一张图。
不要画正式流程图，不要复刻旧案例。
请重新发明一个新的低科技隐喻，让仓老师参与核心动作。
```

---

## 改图：去掉标题

```text
Use $cang-skill 帮我编辑这张图。
去掉左上角的"<标题文字>"标题和下划线，其他内容保持不变。
不要新增任何文字或物件。
```

---

## 改图：增强仓老师参与感

```text
Use $cang-skill 这张图方向对，但仓老师有点像装饰。
请保持核心意思不变，重生成一版：让仓老师成为真正推动结构运转的人。
画面更怪一点，但仍然纯白、清爽、少字。
```

---

## 生成一组风格样片

```text
Use $cang-skill 输出 5 个不同主题的仓老师正文配图效果。
主题分别覆盖：信息过载、产品验证、内容复利、一人公司、信任建立。
每张单独生成，不要拼成一张。
```

---

## 公众号封面生成（封面模式）

```text
Use $cang-skill 帮我做一张公众号封面，走公众号封面模式，2.35:1。

主标题：轻量档反超旗舰
补充信息：284B总参 激活13B
核心隐喻元素：一个举着指挥棒的小机器人，用橙色线条指向补充信息
仓老师：侧身，一手指向标题，一手张开举起，表情夸张大笑
上衣颜色：品牌绿 #69b076

参考图：assets/examples/covers/01-deepseek-v4-flash-reference.png
（仅供构图和姿势参考，不要照抄它的颜色、文字或机器人造型）
```

## 配图 + 自动保存到 workspace

```text
Use $cang-skill 为下面这篇文章生成配图，并保存到 workspace：

<粘贴文章>

要求：
- 生成 4-6 张 16:9 配图
- 按顺序命名：01-topic.png、02-topic.png……
- 保存到 assets/<article-slug>/
- 输出每张图的用途说明
```
